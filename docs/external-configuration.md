# External configuration

Brief’s public web service needs only the public Supabase connection values at runtime: `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY`. These must be set in the chosen host’s secret/configuration interface; they are not committed to this repository.

The same-origin public API does not require CORS configuration. If a separately hosted browser client is intentionally used, `CORS_ORIGINS` may list trusted HTTP(S) origins as a comma-separated list without paths. Wildcards, path prefixes, and untrusted origins are rejected.

The finite private workspace-cycle command additionally requires server-only `SUPABASE_SERVICE_ROLE_KEY`, `GEMINI_API_KEY`, `OPENROUTER_API_KEY`, and `GROQ_API_KEY` values. `GEMINI_MODEL` and `OPENROUTER_MODEL` are optional model overrides; the default path uses `gemini-2.5-flash` first, then the free OpenRouter chain `minimax/minimax-m3:free`, `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`, and `poolside/laguna-s-2.1:free` in order. The application retries the next model after an OpenRouter failure and locally validates JSON before accepting a response. The free models may be subject to OpenRouter’s rate limits or temporary availability. The worker validates its environment before it can begin, uses a database lease plus a Kolkata-calendar idempotency key, and exits after one bounded run. None of these values belong in browser builds, source control, client-side configuration, logs, or public documentation examples.

The workspace cycle runs through `.github/workflows/workspace-cycle.yml` at **09:00 Asia/Kolkata every Sunday, Wednesday, and Friday**. The GitHub Actions five-field UTC expression is `30 3 * * 0,3,5`. GitHub-hosted standard runners are free for this public repository, subject to GitHub’s usage policies and normal schedule-delivery delays. The workflow builds the production bundle and runs `pnpm refresh:workspace` with encrypted repository secrets. It writes source-linked, categorized changes and grounded idea/expansion records; the public service reads only rows explicitly marked public.

A separate Render Cron Job was evaluated but not created because Render required payment-card verification. The Render blueprint at `deploy/render-workspace-cycle.render.yaml.example` remains an optional paid-host alternative; it is not part of the active scheduler. Before the first successful GitHub Actions cycle, the public workspace safely displays its empty/next-cycle state; after a successful cycle, it displays only the resulting public rows.
